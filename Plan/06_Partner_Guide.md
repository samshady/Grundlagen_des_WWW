## Woche 1: Git + Elm kennenlernen

### Git installieren
```bash
sudo apt install git
```

### Grundlegende Git-Kommandos

```bash
# Repository klonen
git clone <url>

# Änderungen prüfen
git status

# Änderungen hinzufügen
git add .

# Commit machen
git commit -m "Nachricht"

# Hochladen
git push
```
